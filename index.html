✨ 功能模块

📋 Listing 优化生成

爬取竞品标题/五点/产品描述 → DeepSeek v4 Pro AI重写 → 12语种本地化翻译输出。支持字数限制、多版本一键切换、独立复制。

🖼️ A+ Content 生成

AI生成品牌故事、产品对比矩阵、场景化图文模块、技术规格表。支持图片上传+DeepSeek视觉识别。

📊 评论情感分析

竞品评论深度分析：🔥高频痛点分类、⭐高频赞美提炼、💡未满足需求挖掘、🎯使用场景洞察、📈综合评分卡。

🌍 多语言本地化

EN/FR/DE/ES/IT/JP/PT/NL/PL/SV/AR/TR 12种语言，非直译而是符合当地用语习惯的文化适配翻译。

🔍 智能爬虫引擎

Cheerio静态页解析 + Puppeteer无头浏览器双引擎。产品页自动爬取，评论页支持Cookie登录态爬取。每URL状态可视化，失败无数据时主动提醒。

📋 透明化反馈

每个竞品URL爬取结果可视（✅成功/❌失败），无竞品数据时弹窗警告，拒绝静默失败。支持手动粘贴兜底。

🛠️ 技术架构

后端: Node.js + Express (6 RESTful API 路由)

前端: 原生 HTML/CSS/JS SPA（零框架依赖，3模式切换）

爬虫: Cheerio（静态页）+ Puppeteer（动态页/Cookie登录）

AI: DeepSeek v4 Pro API（deepseek-chat）
